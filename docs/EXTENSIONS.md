# Extensions Directory

A catalog of every installable extension shipped from this repo's marketplace: plugin bundles, their agents/skills/commands/hooks/MCP servers, and the individual skill/agent micro-entries. `.claude-plugin/marketplace.json` is the authoritative installable list; it is generated by `.github/scripts/generate-marketplace.py`.

Repo-local dev tooling under `.claude/` is excluded because it supports developing this repo and is never published to the marketplace. Drafts under `skills/in-progress/` are also excluded.

## Host compatibility

These extensions install in both Claude Code and GitHub Copilot CLI. `.github/host-compat.json` is the source of truth for host differences; do not duplicate that matrix here. The key Copilot CLI caveats are that it silently ignores agent `model:` values, agent `color:`, and skill `disable-model-invocation`, so extension bodies must still behave sensibly without those controls.
